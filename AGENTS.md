# Documentación de Agentes de IA (AGENTS.md)

Este documento detalla el uso de herramientas de Inteligencia Artificial como apoyo durante el desarrollo del proyecto **Fya Social Capital**.

## Objetivo

Utilizar la IA como asistente ("Pair Programming") para acelerar tareas repetitivas, resolver conflictos de configuración e implementar buenas prácticas bajo supervisión técnica.

## Tareas Delegadas

- **Debugging y Base de Datos:** Diagnóstico y solución del error de carga inicial en H2, aplicando `spring.jpa.defer-datasource-initialization=true` para sincronizar la ejecución del `data.sql` con Hibernate.
- **Desarrollo Frontend:** Estructuración del esquema de validación mediante `ReactiveFormsModule` y actualización de la vista HTML utilizando la sintaxis de control de flujo `@if` de Angular.
- **Desarrollo Backend:** Creación automatizada de los scripts SQL (`INSERT`) para poblar la base de datos de prueba.

## Conclusión

La IA funcionó estrictamente como un habilitador técnico.
